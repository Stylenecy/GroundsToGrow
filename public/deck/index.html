01 — The Problem at Scale

Setiap hari, sesuatu yang bernilai
kita buang ke tempat sampah.

160JT KG
estimasi ampas kopi terbuang di Indonesia tiap tahun — dari ratusan ribu kedai.
~80RB TON
CO₂-eq potensial dari metana ampas yang membusuk di TPA. (≈ 0.5 kg CO₂-eq / kg ampas)
Rp 0
nilai yang ter-capture hari ini. 100% jadi beban biaya disposal, bukan pendapatan.

Bukan karena tidak berguna — tapi karena tidak ada yang mengkoordinasikan pihak-pihak yang sebenarnya saling membutuhkan.

02 — The Reframe

Ini sampah.

Ini idle resource dengan 8 sisi ekosistem.

Cara berpikir lama melihat ampas sebagai akhir dari sebuah rantai linier. Kami melihatnya sebagai titik awal sebuah loop — di mana 8 pihak berbeda masing-masing punya kepentingan untuk menambah nilai.

Bukan biaya — supply

Kedai kopi: dari bayar disposal jadi dapat ESG badge + dashboard. Limbah jadi aset.

Bukan acak — terkoordinasi

Smart Matching menggantikan grup WhatsApp & kontak personal dengan trust layer + reputation.

Bukan linear — sirkular

Kopi pagi → skincare malam → kompos → tanaman. Nilai berputar, tidak berakhir di TPA.

resource, not rubbish ✿

03 — Klasifikasi Teori · Materi P15

Ini bukan digitalisasi proses lama.
Ini Digital Disruption.

Di-map ke 9-Level Model of Digital Disruption (Bu Dhika) — tiga level kunci yang jadi backbone pitch:

L4
Radical Disruption — Transition Intensity
Model bisnis baru, pasar baru (UMKM hilirisasi sebagai economic actor), arsitektur industri baru. Bukan migration, bukan conversion.
L6
Core Value Digital Interface — Strategy Type
Orchestrator antar pihak — pola Airbnb / Uber. Asset-light matchmaker, bukan waste collector / processor.
L8
8-Entity Value Constellation — Value Network
Jaringan 8 entitas dengan platform sebagai pusat. Setiap node memberi & menerima nilai — bukan rantai linier.
Pitch line

“Business Model Disruption pada Level 4 (Radical), dengan strategi Core Value Digital Interface (Level 6), membentuk 8-Entity Value Constellation (Level 8) di sektor circular economy.”

08 — Network Effects

Tiap entitas baru menaikkan nilai 7 sisi lain.

Coffee shop tambah → UMKM happy → produk lebih banyak → konsumen naik → brand sponsor tertarik → fund besar → Kampus & DLH lihat dampak → endorse → coffee shop baru tertarik. Loop yang mempercepat dirinya sendiri.

Data Network Effect

Makin banyak submit → matching makin akurat, prediksi waste flow makin presisi.

Trust / Reputation

Eco-Badge race antar kedai + Verified Cert jadi switching cost UMKM.
